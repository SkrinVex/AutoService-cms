# Информационная система «Автосервис»

Десктопное приложение для автоматизации учёта и управления заказами в автосервисе. Разработано в качестве курсового проекта на стеке C++17 и фреймворке Qt 6 (QtWidgets).

---

## 📌 Основные возможности

- **Управление заказами**:
  - Создание новых заказов в удобном модальном окне.
  - Изменение статуса заказа («Принят», «В работе», «Готов к выдаче», «Закрыт») в один клик или по двойному клику по строке.
  - Удаление заказов с подтверждением действия.
- **Поиск и фильтрация**:
  - Регистронезависимый «живой» поиск с поддержкой кириллицы по ФИО клиента и государственному регистрационному номеру автомобиля.
  - Фильтрация по текущему статусу заказа.
  - Быстрый сброс фильтров к исходному состоянию.
- **Интеграция с базой данных**:
  - Встроенная реляционная СУБД SQLite (`QSQLITE`).
  - Автоматическое создание файла базы данных `autoservice.db` и структуры таблиц при первом запуске.
  - Транзакционность при создании заказа: привязка клиента, автомобиля и работ выполняется в рамках единой атомарной транзакции с откатом при ошибках.
  - Включение внешних ключей (`PRAGMA foreign_keys = ON;`) с каскадным контролем целостности.
- **Экспорт данных**:
  - Выгрузка текущей отфильтрованной выборки заказов в файл CSV.
  - Запись с меткой порядка байтов UTF-8 BOM (`\xEF\xBB\xBF`) и разделителем-точкой с запятой (`;`) для корректного открытия в Microsoft Excel без кракозябр.
- **Статистика в реальном времени**:
  - В строке состояния отображается количество видимых записей, общее число заказов и суммарная стоимость выбранных работ.

## 🛠 Стек технологий

- **Язык**: C++17
- **GUI-фреймворк**: Qt 6 (модули `Core`, `Gui`, `Widgets`, `Sql`)
- **Система сборки**: CMake (минимальная версия 3.16)
- **СУБД**: SQLite 3 (через встроенный в Qt драйвер `QSQLITE`)
- **Интерфейс**: Чистый C++ код (без `.ui` файлов Qt Designer) для максимальной переносимости и простоты сборки

## 🗄 Структура базы данных

База данных содержит 3 связанные таблицы:

1. **`clients`** (Клиенты):
   - `id` (INTEGER PRIMARY KEY AUTOINCREMENT) - идентификатор клиента.
   - `full_name` (TEXT NOT NULL) - фамилия, имя и отчество.
   - `phone` (TEXT NOT NULL) - контактный номер телефона.

2. **`cars`** (Автомобили):
   - `id` (INTEGER PRIMARY KEY AUTOINCREMENT) - идентификатор автомобиля.
   - `client_id` (INTEGER NOT NULL, FOREIGN KEY -> `clients.id`) - владелец.
   - `brand` (TEXT NOT NULL) - марка.
   - `model` (TEXT NOT NULL) - модель.
   - `plate_number` (TEXT NOT NULL) - госномер.

3. **`orders`** (Заказы):
   - `id` (INTEGER PRIMARY KEY AUTOINCREMENT) - номер наряд-заказа.
   - `car_id` (INTEGER NOT NULL, FOREIGN KEY -> `cars.id`) - обслуживаемый автомобиль.
   - `description` (TEXT NOT NULL) - перечень работ и запчастей.
   - `status` (TEXT NOT NULL) - статус («Принят», «В работе», «Готов к выдаче», «Закрыт»).
   - `cost` (REAL NOT NULL) - общая стоимость работ в рублях.
   - `date_created` (TEXT NOT NULL) - дата и время фиксации заказа.

## 🚀 Инструкция по сборке и запуску

### Сборка под Linux

1. Установите зависимости (Qt 6, компилятор C++17, CMake):
   ```bash
   # Ubuntu / Debian:
   sudo apt update
   sudo apt install build-essential cmake qt6-base-dev libqt6sql6-sqlite
   ```

2. Сконфигурируйте и соберите проект:
   ```bash
   cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
   cmake --build build -j$(nproc)
   ```

3. Запуск автоматических тестов:
   ```bash
   ctest --test-dir build --output-on-failure
   ```

4. Запуск приложения:
   ```bash
   ./build/AutoService
   ```

---

### Сборка под Windows

#### Вариант 1: Сборка через Visual Studio / MSVC
1. Откройте командную строку разработчика (`x64 Native Tools Command Prompt for VS 2022`).
2. Укажите путь к Qt 6 в переменной `CMAKE_PREFIX_PATH`:
   ```cmd
   cmake -B build -S . -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:\Qt\6.7.2\msvc2022_64"
   cmake --build build --config Release
   ```
3. Соберите зависимости в каталог с исполняемым файлом:
   ```cmd
   windeployqt --release --compiler-runtime build\AutoService.exe
   ```
4. Запустите:
   ```cmd
   build\AutoService.exe
   ```

#### Вариант 2: Готовая сборка через GitHub Actions
В репозитории настроен автоматический CI/CD pipeline в файле `.github/workflows/build.yml`. При каждом коммите в ветку `main` в разделе **Actions** формируется архив `AutoService-Windows-x64.zip`, содержащий скомпилированный бинарник со всеми необходимыми библиотеками Qt и компилятора MSVC.
